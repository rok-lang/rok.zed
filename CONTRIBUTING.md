# Contributing to rok.zed

The Zed extension for Rok: languages and tree-sitter queries for `.rok`
and `.rokon`, and a small Rust extension that starts `rokls`.

## Layout

- `extension.toml`: manifest; grammars pinned to a rok-syntax commit.
- `languages/rok`, `languages/rokon`: `config.toml` and queries.
  `highlights.scm` and `injections.scm` are generated by `scripts/sync`;
  `brackets.scm`, `indents.scm`, `outline.scm`, `overrides.scm` and
  `textobjects.scm` are edited here.
- `src/lib.rs`: finds `rokls` and builds its command line.
- `rok-syntax.rev`: the pinned rok-syntax commit.

## Development

Install Rust with rustup and the wasm target Zed builds for:

```sh
rustup target add wasm32-wasip2
cargo build --release --target wasm32-wasip2
```

In Zed, run `zed: install dev extension` and pick this checkout. After a
change, press **Rebuild** on the extension in the Extensions page.
`zed: open log` shows build and `rokls` errors; start Zed with
`zed --foreground` for more.

## Queries

Every query must compile against the pinned grammar. Check them with the
tree-sitter CLI over rok-syntax's corpus:

```sh
git -C ../rok-syntax checkout "$(cat rok-syntax.rev)"
(cd ../rok-syntax && npm ci)
scripts/check-queries ../rok-syntax
```

Capture names follow
[Zed's list](https://zed.dev/docs/extensions/languages#syntax-highlighting).
A later pattern wins over an earlier one for the same node, as in
rok-syntax. To change highlighting, change rok-syntax's
`highlights.scm`, or the capture map in `scripts/sync`.

## Bumping the grammar

1. Land the grammar or query change in rok-syntax and push it.
2. Sync from a checkout at that commit:

   ```sh
   scripts/sync --from ../rok-syntax
   ```

   This writes `rok-syntax.rev`, the `rev` of both grammars in
   `extension.toml`, and the generated queries.
3. Run `scripts/check-queries ../rok-syntax`, fix the Zed-only queries if a
   node was renamed, try it as a dev extension, and commit.

CI runs `scripts/sync --check`, the query check and the wasm build.

## Submitting

Open a pull request against `main`. By contributing you agree that your work is
licensed under both MIT and Apache-2.0, the project's dual license.

## Releasing

The version in `extension.toml` and `Cargo.toml` is independent of the Rok
toolchain. Bump both, add an `## X.Y.Z` entry to `CHANGELOG.md`, commit on
`main`, then open a pull request against
[zed-industries/extensions](https://github.com/zed-industries/extensions)
that adds or bumps the `extensions/rok` submodule and its entry in
`extensions.toml`.
